## 2025-02-12 - Memory Exhaustion (DoS) via Unbounded Body Read
**Vulnerability:** The `_read_limited` function in `app/main.py` checks `request.headers.get("content-length")` against a maximum bound, but then calls `raw = await request.body()` which blindly reads the entire request stream into memory. By sending a request using chunked transfer encoding (without a `content-length` header), an attacker can feed infinite data into the server until memory is exhausted, causing a Denial of Service (DoS) vulnerability.
**Learning:** Checking `content-length` is insufficient to prevent unbounded body reads since chunked requests omit this header. `request.body()` bypasses limits when reading chunked streams.
**Prevention:** Rather than using `request.body()`, one should iterate over `request.stream()` and manually accumulate chunks while tracking the length, raising an exception as soon as the total length exceeds the maximum allowed size. Then we can inject the accumulated bytes back into `request._body` to allow `request.json()` to function correctly later.
