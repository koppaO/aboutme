## 2024-05-10 - Race Condition in Rate Limiting
**Vulnerability:** A race condition existed in the rate limiting implementation (`app/auth.py`), allowing concurrent requests to bypass the maximum failed attempt limit (`MAX_FAILURES`). The rate limiting logic was checking `is_locked(ip)` and waiting until *after* authentication (which uses slow PBKDF2 hashing) to record a failure using `register_failure(ip)`.
**Learning:** During the slow authentication check, multiple concurrent login attempts would all evaluate `is_locked(ip)` to `False` before any single failure could be recorded. This enabled attackers to make arbitrarily many concurrent attempts against the slow authentication endpoint, bypassing the rate limit lock.
**Prevention:** Always register actions or failures *before* yielding control or performing slow synchronous/asynchronous tasks (e.g. hashing passwords). In this case, moving `register_failure(ip)` immediately after the lock check, before proceeding with the actual login check, ensures attempts are synchronously counted. If the authentication succeeds, the failures are then cleared.

## 2024-10-24 - Rate Limiting Bypass via IP Spoofing
**Vulnerability:** A rate-limiting bypass existed in `app/auth.py` where the IP extraction logic (`client_ip`) rejected the `X-Real-IP` header entirely if it contained a comma (e.g. from multiple proxies). This allowed an attacker to append a comma and arbitrary IP to the `X-Real-IP` header to fall back to the generic or internal request client IP, resulting in the rate limit counter failing to track the attacker's actual IP accurately across requests.
**Learning:** Checking for invalid characters and returning a generic response instead of parsing properly can inadvertently disable security controls that rely on that parsed data.
**Prevention:** Rather than rejecting the string, parsing it to extract the first valid entry (e.g. `real.split(",")[0].strip()`) ensures the rate limiting mechanism receives a consistent IP for tracking, even when multiple proxies are in the chain or when spoofing is attempted.
